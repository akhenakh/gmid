# gmid shortcuts

| Shortcut | Action |
| --- | --- |
| `Space` | Play / pause |
| `Escape` | Stop, or close the topmost panel; also exits presentation mode |
| `←` / `→` | Step to the previous / next played moment |
| `Shift`+`←` / `Shift`+`→` | Step by bar |
| `F11` | Toggle presentation mode (`Esc` also exits) |
| `Ctrl`/`Cmd`+`B` | Show/hide the left Setup panel |
| `Ctrl`/`Cmd`+`Up` / `Down` | Zoom the whole app (Shirei does not report `+`/`-` punctuation portably) |
| `Ctrl`/`Cmd`+`O` | Open the Library |
| `Ctrl`/`Cmd`+`P` | Settings (Ctrl+, is reserved for a later pass; Shirei does not report punctuation keys portably) |
| `Ctrl`/`Cmd`+`Shift`+`M` | Console Mixer |
| Mouse wheel on the roll | Scrub ±2 s |
| `Shift` + wheel on the roll | Fine scrub ±0.15 s |
| Click the roll | Seek |
| Click or drag the keyboard | Play / glissando |

## Note Editor (edit mode)

| Shortcut | Action |
| --- | --- |
| Click a note | Select it |
| `Shift`+click | Add / remove from selection |
| Drag a note | Move it |
| Drag the right edge | Resize it |
| `Delete` / `Backspace` | Delete the selection |
| `Ctrl`/`Cmd`+`Z` | Undo |
| `Ctrl`/`Cmd`+`Shift`+`Z` or `Ctrl`/`Cmd`+`Y` | Redo |
| Marquee tool | Box-select notes |
| Pen tool | Click empty space to add a note |
| `Esc` | Leave the editor |

Mixer: `Esc` closes the console and saves a changed mix as a new version.
